Spray bottle:
PumpAssembly_OPENABLE is a separate node with a pivot at the bottle neck. Manipulate this node in React Three Fiber / three.js for open/close animation. Bottle_Liquid is also separate for fill-level animation.

These are web-ready base assets with clean PBR materials and scene-separated parts. Packaging print is reference-inspired based on the supplied artwork; it is not a scan of the original physical package. Exact manufacturing geometry and label artwork should be replaced by production CAD / print artwork when available.
